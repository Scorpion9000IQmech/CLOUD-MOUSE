## Instructions(consult the original file with all parts for reference):

1.print the shell, MID, BASE, and battery tab(that is everything which is not provided in the kit)

2.place the pcb on the correct orienation on the base, with the sensor facing downwards(attach the sensor in its place before placing the pcb)

3.place the mouse wheel into the designated place on the pcb

4.attach the two battery pads onto their place, slip the wire into the tiny slit to make it neater and insert the other end into the pcb

5.place the mid on top of these and screw the 3 screw holes in, using the provided screws

6.place the shell on top, fitting the rest of it within, screw the holes below the base into the shells holes to lock it in

7. place the battery in the place below and then the battery tab to lock it in

9. insert the usb into your computer and it should work easy as that
